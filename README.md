# Little Man Computer
### This is a python implementation of [Peter Higginson's](https://peterhigginson.co.uk/LMC/) LMC

## Features:
+ emulator (emu folder):
    + 100 memory addresses
    + Accumulator to hold results of calculations
    + Program counter to hold the location of the next instruction
    + Takes a 'binary' file as input and produces the corresponding output (see example programs in the test_progams folder)

+ Assembler (asm folder):
    + takes a file as input and converts it into the corresponding 'binary' output
    + ...
